# cw02 - Trzy jakości promptu

## Przeznaczenie
Porównanie wpływu precyzji promptu na analizę nieznanego kodu routingu.

## Wejścia i rezultat
Wejściem są moduły `src/routing/`; trzy osobne rozmowy Ask otrzymują różne prompty. Rezultatem jest `portfolio/cw02-prompty.md` z obserwacjami.

## Kontrole
Uruchom `npm run ksiegowanie`, sprawdź wynik dla R12 i odczytaj implementację `dopasujRegule`. Każdy prompt jest wykonywany w odrębnym czacie.
