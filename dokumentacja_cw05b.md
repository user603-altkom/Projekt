# cw05b - Publiczne wzorce Copilota

## Przeznaczenie
Znalezienie jednego użytecznego wzorca w publicznych instrukcjach i sprawdzenie go we własnej pracy.

## Wejścia i rezultat
Źródłami są publiczne materiały VS Code, GitHub Skills i Awesome Copilot. Rezultatem jest notatka: link, opis wzorca i jeden pomysł do próby.

## Kontrole
Należy wskazać konkretny fragment źródła, wyjaśnić jego działanie i przetestować wybrany pomysł. Nie uruchamia się pełnego kursu GitHub Skills.
