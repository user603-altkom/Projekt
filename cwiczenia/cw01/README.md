# Ćw. 01 — Co wiemy, a co dopowiedział model?

**Dzień 1, 10:00–10:20 · 20 min · Copilot w VS Code**

Franek twierdzi, że „limity już są”. Otwórz repo i poproś Copilota o drogę od pliku danych do ekranu. Nie zlecaj jeszcze zmian.

1. Zapytaj: „Gdzie obliczamy przekroczenie limitu i jak trafia ono na ekran? Przy każdym twierdzeniu podaj plik, symbol i dowód. Oddziel istniejący kod od proponowanej zmiany”.
2. Otwórz wskazane pliki. Sprawdź co najmniej trzy twierdzenia. Obejrzyj `src/operator/limitRows.ts` — czy implementacja istnieje?
3. Porównaj odpowiedź z obserwacją strony dla źródła „Wynik z repo”. Wyświetlenie demo nie dowodzi integracji.
4. Zapisz tabelę twierdzenie / dowód / potwierdzone, obalone lub nieustalone.

**Gotowe:** trzy sprawdzone twierdzenia, co najmniej jedno ograniczenie odpowiedzi, wskazane brakujące połączenie. Jeżeli AI powiedziało prawdę, pokaż to. Nie trzeba sprowokować halucynacji. Pewny ton ani ostrożne słowa nie rozstrzygają prawdziwości.

**Podstawa:** śledź dwa pliki wskazane przez prowadzącego. **Rozszerzenie:** sprawdź deklarację „brak limitu oznacza zero” na kodzie i przykładzie. Popraw instrukcję pytania na podstawie dowodu.
