# cw05 - Wejście w nieznany kod

## Przeznaczenie
Udokumentowanie działania modułu odsetek na podstawie kodu i odróżnienie go od niepotwierdzonych interpretacji.

## Wejścia i rezultat
Analizowane są `src/interest/accrue.ts`, wersja Java oraz przypadki danych. Rezultatem jest `portfolio/cw05-mapa.md` z mapą wejście--funkcja--wynik i trzema dowodami.

## Kontrole
Trzy twierdzenia wskazują kod albo są nazwane niewiadomymi; partner odtwarza ich źródła. Opcjonalnie uruchom `npm test -- tests/interest/accrue.test.ts`.
