# cw07 - Diagnoza i poprawka importu

## Przeznaczenie
Przejście od wcześniejszego testu importu do wyjaśnienia różnicy 23 groszy i minimalnej poprawki.

## Wejścia i rezultat
Wejściem jest test z `cw06`, parser i pełny wyciąg. Powstaje `portfolio/cw07-diagnoza.md` z przyczyną oraz expected/actual przed i po zmianie.

## Kontrole
Uruchom `npm run raport` i test importu. Zachowaj wynik, także gdy raport nadal się nie zgadza; danych ani oczekiwania nie wolno zmieniać w celu ukrycia błędu.
